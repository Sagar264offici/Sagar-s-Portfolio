# Audio slot

`portfolio-theme.mp3` is currently the **Timeless (Instrumental)** track supplied by
Sagar. The site plays it in a loop whenever the visitor enables sound.

- Sound is **off by default**; the SOUND toggle enables it (browser autoplay policy).
- If the file is ever removed, the site automatically falls back to an original
  Web Audio ambient pad — the feature never breaks.
- The track was provided by Sagar for use on this portfolio; keep the licensing
  paperwork for it on hand. To swap the music, just replace this file — no code
  changes needed.
